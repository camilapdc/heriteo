# heriteo

website for heriteo: herit{age} e{vent} o{rganisation}.

live at https://camilapdc.github.io/heriteo/

## editing

- **about**: change the text inside the `<p>` … `</p>` lines in `about.html`.
- **events**: in `events.html`, copy the hidden example event (between `<!--` and `-->`), remove those two markers from your copy and fill it in.
- **menu / title**: these are repeated in `index.html`, `about.html` and `events.html`; change all three.

after editing, commit and push: the live site updates by itself within a minute or two.

## font

the site uses MonoLisa when it can find it. it is a paid font, so put your licensed web files in `fonts/` as
`MonoLisa-Regular.woff2`, `MonoLisa-Light.woff2` and `MonoLisa-Bold.woff2`. until then JetBrains Mono is used.
